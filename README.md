# 홍보물 자동 생성기 (브릿지 커피)

매장 사진과 가게 정보 텍스트만 넣으면, **인스타그램용 정사각형 사진**과
**채널별 홍보 문구**를 한 번에 만들어 주는 자동화 도구입니다.
개발을 모르는 가게 사장님이 매주 혼자 쓸 수 있도록 만들었습니다.

## 하는 일

1. `자료` 폴더의 사진(jpg, jpeg, png)을 **1080 x 1080 정사각형**으로 변환합니다.
   - 사진 가운데를 기준으로 잘라내므로 세로·가로 사진도 찌그러지지 않습니다.
   - 원본 사진은 읽기만 하고 절대 바꾸지 않습니다.
2. 사진 오른쪽 아래(가장자리에서 40px 안쪽)에 **로고**를 넣습니다.
   - 로고 너비는 사진 가로의 15%이고, 뒤의 사진이 흐릿하게 비치는 반투명 바탕 위에 올라갑니다.
   - `로고.jpg`를 먼저 찾고, 없으면 `로고.png`를 사용합니다. 둘 다 없으면 로고 없이 진행합니다.
3. `가게 정보.txt`를 읽어 **홍보 문구**를 만듭니다. AI 호출 없이 양식에 정보를 채우는 방식이라 무료입니다.
   - 인스타그램용: 감성형 / 정보형 / 이벤트형 (각 150자 안팎) + 해시태그 10개
   - 네이버 블로그용: 제목 + 본문 (1000자 안팎, 해시태그 없음)
   - 카카오톡 단골 공지용: 3줄 이내
   - 말투는 사장님 글(`내 말투.txt`) 분석 결과에 맞춰 "-습니다", 한 줄 한 문장으로 씁니다.
     이모지는 `내 말투.txt`의 사용 습관을 읽어 자동으로 맞춥니다.
4. 결과를 `완성/날짜_시각/` 새 폴더에 저장합니다. 실행할 때마다 폴더가 따로 생겨 결과가 섞이지 않습니다.

## 사용 방법

1. `자료` 폴더에 이번 주 사진을 넣습니다.
2. `자료/가게 정보.txt`에서 `이번 주 홍보할 것:` 아래 줄만 새 내용으로 고칩니다.
3. 아래 명령을 실행합니다.

```
python 인스타변환.py
```

자세한 설명은 [사용설명서.txt](./사용설명서.txt)를 참고하세요.

### 웹앱으로 쓰기 (폰·PC)

파이썬 없이 브라우저에서도 같은 기능을 쓸 수 있습니다.
`index.html` 하나로 동작하며, 사진은 기기 안에서만 처리되고 서버로 올라가지 않습니다.

- 주소: https://pisces20557-afk.github.io/Marketing-generate-app/
- **설치해서 쓰기:** 주소에 접속한 뒤
  - 안드로이드(크롬): ⋮ 메뉴 → "앱 설치" 또는 "홈 화면에 추가"
  - 아이폰(사파리): 공유 버튼 → "홈 화면에 추가"
  - PC(크롬·엣지): 주소창 오른쪽 설치 아이콘 → "설치"
- 한 번 설치하면 로고 아이콘으로 열리고, 인터넷이 없어도 열립니다.
- 홍보 문구는 파이썬 프로그램과 같은 규칙으로 만들어집니다. (같은 가게 정보로 비교해 결과가 같음을 확인했습니다.)
- 결과 사진은 폴더에 저장되지 않고 내려받기 폴더로 저장됩니다. 사진·문구를 한 번에 받는 zip 버튼이 있습니다.

### 가게 정보.txt 쓰는 규칙

```
가게 이름: 브릿지 커피
위치: 광주 북구 비엔날레 지구
가게 특징: 직접 로스팅하는 스페셜티 커피, 조용한 1인 좌석 많음
주 고객층: 30~40대 직장인, 근처 사무실 손님

이번 주 홍보할 것:
- 신메뉴 '흑임자 라떼' 5,500원, 국산 흑임자를 직접 갈아서 넣음, 고소하고 달지 않음
- 오전 11시 이전 방문 시 아메리카노 500원 할인
```

- 홍보할 내용은 줄 앞에 `- `를 붙입니다.
- 신메뉴 이름은 작은따옴표(`'...'`)로 감쌉니다. 가격은 `5,500원`처럼 씁니다.
- 할인·이벤트 줄에는 `할인`, `이벤트`, `증정`, `무료`, `쿠폰` 중 하나를 넣습니다.

## 결과물 예시

```
완성/
└── 20261028_0930/          # 실행한 날짜_시각
    ├── 20261028_01.jpg     # 1080 x 1080 사진 (로고 포함)
    ├── 20261028_02.jpg
    └── 홍보문구.txt         # 인스타 / 블로그 / 카카오톡 문구
```

## 폴더 구조

```
홍보자동화/
├── 인스타변환.py     # 메인 스크립트 (사진 변환 + 문구 생성)
├── index.html        # 웹앱 본체 (브라우저에서 사진 변환 + 문구 생성)
├── manifest.webmanifest, sw.js, icons/   # 웹앱 설치용 설정·오프라인 저장·아이콘
├── 로고.ico          # 바탕 화면 바로가기용 아이콘
├── 사용설명서.txt     # 사장님용 사용 안내
├── CLAUDE.md         # Claude와 작업할 때의 규칙
├── 자료/             # 입력: 사진, 가게 정보.txt, 내 말투.txt, 로고.png
└── 완성/             # 출력: 실행할 때마다 날짜_시각 폴더가 생김
```

## 필요 환경

- Windows
- Python 3.12
- Pillow (이미지 처리 라이브러리)

```
pip install pillow
```

## 참고

- 같은 분에 두 번 실행하면 폴더 이름 뒤에 `_2`, `_3`이 붙어 서로 덮어쓰지 않습니다.
- 홍보 문구는 가게 정보에 있는 내용만 사용하며, 없는 사실은 지어내지 않습니다.
- 가게 정보 파일이 없거나 형식을 읽지 못하면 문구 생성만 건너뛰고 사진 변환은 계속 진행합니다.
